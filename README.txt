LEGACY ENGINEERING WEBSITE — V1

Files:
- index.html
- styles.css

Before launch:
1. Replace hello@yourdomain.com in index.html with the final business email.
2. Replace the temporary company name if you choose a different brand.
3. Deploy the folder to Vercel, Netlify, Cloudflare Pages, or another static host.
4. Point your domain DNS to the hosting provider.
5. For a production lead form, replace the mailto form with a form service or serverless endpoint.

The site is intentionally dependency-light: one HTML file + one CSS file.
